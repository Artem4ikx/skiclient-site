Установка

Пять шагов до первой катки

Если Fabric у вас уже стоит — переходите сразу к шагу 3.

1

Установите Fabric Loader

Скачайте установщик с fabricmc.net, выберите версию Minecraft и нажмите «Install». В лаунчере появится профиль fabric-loader-1.21.11.

2

Скачайте Fabric API

SkiClient использует Fabric API. Возьмите версию для 1.21.11 на Modrinth.

3

Положите файлы в папку mods

Скопируйте skiclient-.jar и Fabric API в папку модов. Если папки нет — создайте её.

%appdata%\.minecraft\mods
4

Запустите игру через профиль Fabric

В лаунчере выберите профиль Fabric и нажмите «Играть». SkiClient загрузится вместе с игрой.

5

Нажмите RSHIFT

Откроется меню клиента. Включите нужные модули, выберите тему, а если есть ключ — введите его в карточке профиля внизу слева.
