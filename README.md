# Сайт SkiClient

Статический сайт без сборки: HTML, CSS и JS. Чтобы посмотреть, откройте `index.html` в браузере. Для публикации загрузите всю папку на любой хостинг (GitHub Pages, Netlify, Cloudflare Pages, nginx).

## Страницы

| Файл | Что там |
|---|---|
| `index.html` | Главная: hero со скриншотом меню, живые превью HUD, темы, быстрый старт |
| `features.html` | Все модули с фильтрами и поиском, панель настроек модуля, конструктор прицела |
| `pricing.html` | Free и Pro, демо активации ключа, таблица сравнения |
| `download.html` | Скачивание `.jar`, требования, инструкция по установке, changelog |
| `faq.html` | Частые вопросы |

## Что поменять перед запуском

Всё в начале `assets/js/data.js`, в блоке `config`:

- `price`, `currency`: цена ключа Pro на 30 дней (99 ₽).
- `buyUrl`: где покупают ключ (бот, магазин и т.п.).
- `discordUrl`, `telegramUrl`: ссылки на сообщество.
- `version`, `jar`, `jarSize`: при выходе новой версии положите `.jar` в `downloads/` и обновите эти поля.

Список модулей там же, в `modules`. Он повторяет `ModuleManager.java` и `ru.json` клиента. Если добавите модуль в клиент, добавьте его и сюда: каталог, таблица сравнения, счётчики и бегущая строка обновятся сами.

## Скриншоты

`assets/img/gui-*.webp` — меню клиента в разных темах (полный размер и версия 960px). Все скриншоты 1920×1080 с одинаковым положением меню, поэтому при смене темы картинка не прыгает. Новые снимайте с той же точки и в том же разрешении.
